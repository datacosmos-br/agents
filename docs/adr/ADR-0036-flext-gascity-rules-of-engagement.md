# ADR-0036 — Project law and selected orchestration

**Status:** Accepted 2026-10-04; authority routing amended 2026-10-20.

## Context

The former global rule copied FLEXT architecture, a retired universal core,
campaign dates and merge timing into another authority. It could impose FLEXT
on unrelated Python projects or infer abandonment from an old cutoff. Git
history retains that evidence; those instructions are retired.

## Decision

Universal execution is owned by this governance bundle. Project architecture is
owned by that project's current branch-matched law. A selected orchestration
contract governs its own roles and runtime; it does not become another source
of project architecture or replace the operator's current intent.

FLEXT activation and source resolution use flext-development and the project
router. Global operator-precedence, session-governance, gascity, Git and tracker
rules own their respective execution subjects. The duplicate flext-gascity rule
and the global rules/flext copies are retired.

## Consequences

A historical campaign cutoff is not current liveness evidence. Orchestration
suspension, retained tracker access and manual execution are distinct facts.
This record grants no early merge, approval waiver, new session or runtime
activation. Current authorization and the native gates govern those effects.
