# ADR-0028 — Census and debt maps are evidence only against the locked runtime

**Status:** Accepted **Date:** 2026-09-27 **Scope:**
`rules/runtime/locked-runtime-census.md`,
`skills/project-wide/configuration/workspace-toolchain/SKILL.md`,
`commands/governance/session-preflight.md`

## Context

On 2026-09-27 the flext-infra PR #947 session (bead `aihub-3bi1m`, handoff
`docs/handoffs/2026-09-27-flext-infra-census-handoff.md` in ai-hub) measured
an 87-finding runtime-census debt and planned a decomposition against it. The
worktree's physical venv had `flext_core` installed from `fe50ef07f` while the
repository's `uv.lock` resolved `3efdfd9ba6` (the `0.12.0-dev` tip). After
`make upg` and the base merge, the same gate reported zero: 76 cures had
landed with the base and the remaining 11 disappeared with the fresh scanner's
exemptions. The debt map — and a session cycle spent planning against it —
was an artifact of an outdated rule engine, not of the code.

The same session also hand-edited a generated skill projection in a consumer
checkout and had to restore it from a sibling worktree, reinforcing that the
projection layer is regenerated by its owner, never patched in place.

## Decision

1. Accept `rules/runtime/locked-runtime-census.md`: before computing,
   triaging, or recording any census/smell/enforcement finding, verify the
   installed runtime equals the lock resolution
   (`direct_url.json` `vcs_info.commit_id` vs the lock's `#<commit>`); on
   mismatch, sync through the declared upgrade verb and recompute. A debt
   record travels with three facts — findings count, scanner commit, lock
   commit.
2. Extend `skills/project-wide/configuration/workspace-toolchain/SKILL.md`
   with the locked-runtime preflight bullet so tool-driven sessions hit the
   check through the router they already load.
3. Accept `commands/governance/session-preflight.md` (route: project) so a
   session startup runs the verification contract, the tracker identity
   check, and the adoption sweep in one declared procedure.
4. Accept `agents/agent-wide/session-scribe.md` as the agent profile that
   owns multi-surface recording discipline (bead = execution, ADR = decision,
   rule = acting law, handoff = reference hub).

## Consequences

- Debt maps computed before a toolchain sync are retired, not repaired; the
  flext-infra census decomposition plan is void.
- Sessions gain one startup command instead of re-deriving the preflight;
  the failure mode "planned against a stale scanner" is checked at the only
  point it can be cheap: before planning.
- Cross-repo decision mirror: the ai-hub fleet records the same decision as
  ADR-0031 (`docs/adr/0031-census-validity-locked-runtime.md`); this ADR is
  the approval authority for the rule/skill/command/agent artifacts.
