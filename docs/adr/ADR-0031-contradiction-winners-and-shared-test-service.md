# ADR-0031 — Contradiction resolution and test-service ownership

**Status:** Accepted 2026-09-29; consolidated 2026-10-20 under the approved
governance repair. Historical tracking: ag-3l2q.

## Context

The original audit resolved conflicting keyring, scanner, warning, storage,
module-size, Git, test and worktree instructions. Its numbered decisions then
became a competing rule body. Later operator decisions changed command bounds,
connectivity applicability and project scope. Git history preserves the original
record and its measurements; it does not reinstate superseded instructions.

## Decision

Each subject has one current normative author. This record locates those authors
and documents supersession; it does not copy their contracts.

| Subject | Current owner |
| --- | --- |
| Authority, authorization and recency | coordination/operator-precedence |
| Keyring and credential behavior | runtime/no-keyring, runtime/encrypted-credential-store |
| Scanner findings | security/scanner-closure |
| Command bounds, outcomes and test verbs | workflow/canonical-commands |
| Gate placement and provisioning | workflow/gate-budget |
| Test applicability, shared service and isolation | testing/observable-runtime |
| Worktree/runtime ownership | coordination/gascity, coordination/shared-venv-guard |
| Source publication and recovery | runtime/atomic-effects, storage |
| Architecture and declaration layout | selected branch-matched project law |
| Configuration-owned values | their typed source; workflow/runtime-is-reality |

The earlier allowance to exclude provisioning from the outer command deadline
is superseded. Earlier capability-deselection text does not replace a newer
project's declared connectivity-prerequisite contract. Neither an old article
nor a general cleanup request changes a protected analyzer policy or grants a
new suppression. Current exact authorization and the protected source decide it.

The duplicated global FLEXT articles are retired. FLEXT's local law and ADRs own
its declaration and generator semantics; flext-development selects them.
Module ceilings are read from their current project owner rather than copied
into global rules or procedures. Current outcome classification preserves native
causes and required red results; it never manufactures success.

## Consequences

Global rules and conditional procedures compose by reference. Provider-managed
blocks are withdrawn by their existing authors, and AI Hub owns deployment of
the integrated bundle. A source edit, catalog load, package test or historical
article does not prove installed propagation or native hook invocation.
