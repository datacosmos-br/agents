| `ADR-0017` | 2026-09-10 | Accepted | Ethics is primordial; change consequence is authorship; operator alignment is a duty; owners are refactored in place, never paralleled.               |
| `ADR-0018` | 2026-09-10 | Accepted | Release line 0.5.0 carries behavioral conscience and the delivery contract; tag grammar is closed as measured.                                        |
| `ADR-0019` | 2026-09-10 | Accepted | The delivery contract is typed data: capsule budget gate at load, closed lifecycle event map, and enforced docs linking.                              |
| `ADR-0020` | 2026-09-10 | Accepted | One `advance` command owns resumption and forced advancement; skill routing owns deltas; the research dossier is referenced evidence.                 |
| `ADR-0021` | 2026-09-16 | Accepted | Operator rulings of 2026-09-15/16 (runtime truth, no rushed work, full landing cycle) are encoded as canonical coordination and ethics rules.         |
| `ADR-0022` | 2026-09-18 | Accepted (emendada) | `~/.agents` becomes a materialized, version-and-digest-stamped global read-only projection (no longer a symlink), managed exclusively by AI Hub — the repo carries no home tooling. |
| `ADR-0023` | 2026-09-19 | Accepted (placement amended by ADR-0025; retirement superseded by ADR-0026) | Worktree discovery/planning is owned by the project's wip program (doc-10 vocabulary); placement follows the active/manual boundary recorded in ADR-0025; retirement is native per ADR-0026. |
| `ADR-0024` | 2026-09-20 | Accepted (warning verdict and facade-module carve-outs amended by ADR-0031) | FLEXT generators emit only what is declared and derive rather than list (fourteen points binding every generator, detector, fix and consumer — owners declared via `__all__`, init propagates, tiers detected, strict compliance as the mechanism); a rule imported from a FLEXT ruling is recorded here before it cites that ruling, and the tag grammar stays four-digit. |
| `ADR-0025` | 2026-09-22 | Accepted | Every manual task uses a dedicated native Git worktree, branch, and physical environment, including during Gas City suspension; orchestration and canonical tracker activation remain independent. |
| `ADR-0026` | 2026-09-24 | Accepted | The projection-landing law is removed and a landed lane retires itself natively with Git after an ancestry proof; no absent executor, planner, or verb defers retirement; lanes outside the session worktree are reached with `git -C`/`env -C … make`. |
| `ADR-0027` | 2026-09-24 | Accepted (renumbered from a colliding ADR-0026 during the closure-campaign F2 integration) | A tool the toolchain installs and the project declares owns its job; when it is installed and unwired, the code grown in its place is the defect, removed in one cutover with its tests, verbs, docs and authorising decisions. Limits blamed on an external tool are measured against it in isolation first, and a note asserting operator authorisation is verified with the operator. |
| `ADR-0028` | 2026-09-27 | Accepted | A census or debt map is evidence only when the executing runtime matches the lock resolution (`direct_url.json` commit vs the lock's `#<commit>`); on mismatch, sync through the declared upgrade verb and recompute, and every debt record carries the findings count, the scanner commit and the lock commit. The same ruling lands the session-preflight command and the session-scribe agent profile. |
| `ADR-0029` | 2026-09-27 | Proposed | Tracker curation routing: one curation owner per tracker; every close carries its proof (file:line, negative reproduction, or successor pointer); shared-tracker closes route id+evidence through the coordinator; beads untouched for over an hour are abandoned, in any state; disposition-before-deletion with inventory; genuine backlog survives staleness. |
| `ADR-0030` | 2026-09-27 | Accepted (renumbered from a colliding ADR-0028 during the acting-cadence integration) | Agent-session environment truth: process context is read from the kernel's cgroup leaf (`.service` vs `.scope`), never from inherited unit markers; guards refuse genuine unit processes and unreadable contexts only; unsetting a marker to pass a guard is a bypass; sessions open with recovery (not rediscovery) and commit a green slice before new exploration. |
| `ADR-0031` | 2026-09-29 | Accepted | Operator decisions of 2026-09-29: eight rule contradictions resolved by their approved winners (keyring and duplicate scanner rules retired, warnings RED, journal is not a backup, size caps only where a project declares them, git plain and never rebased, coverage opt-in, dedicated worktrees); a shared host test service, a budget excluding provisioning and `slow` tests, declarative capability gating with typed `NOT EXECUTED`, no operation retries, scoped environment changes, and checkable test-value rules. |
| `ADR-0032` | 2026-10-01 | Accepted | Sole-executor engagements compose one router skill (`execution-law`, delta-only) over the existing conduct owners, and coordinator resolution becomes the coordinator ladder: active mayor first, otherwise a mail-channel election decided by self-nomination inside the configured abandonment threshold with deterministic tie-break and default self-assumption, otherwise degraded solo with bead-recorded decisions and human-channel reconciliation; no new tunable, no bootstrap membership. |
| `ADR-0033` | 2026-10-03 | Accepted | Cross-actor cooperation uses one channel: gc mail plus the operator relay, so concurrent executor families agree, fix forward, and adopt instead of overlapping in silence. |
| `ADR-0034` | 2026-10-03 | Accepted | Runtime-bearing work is proven on the real running system, every plan declares a recovery path before its first effect, and a broken runtime outranks every other task. |
| `ADR-0035` | 2026-10-03 | Accepted | The fleet is one ecosystem: every runtime registers identity, addressing, and liveness in `rules/communication/ecosystem-systems-registry.md` before it participates. |
