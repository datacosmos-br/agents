# FLEXT-only workflow delta

Apply this rule only when project-local markers/dependencies prove the
repository consumes FLEXT. Never project or activate it for a non-FLEXT project,
a personal agent home, or by reference to an external checkout.

Use the pinned FLEXT artifact and the repository's declared native commands.
Regenerate only through the owning source/template, prove second-run fixed point,
and fix every warning. No local FLEXT bind, symlink, editable/path dependency,
cross-repository reference, compatibility shim, or generated-output hand edit.
