# Gas City Change Lifecycle

Activate only for an explicitly Gas City-coordinated project change. The
repository's Gas City rule is the sole owner of orchestration identity,
dispatch, observation, workspace placement, Git landing, and closure boundaries;
do not copy commands or semantics here.

While runtime is suspended, perform only a static assessment from supplied
configuration. Do not invoke, translate, simulate, or propose an orchestration
command, and do not create a city, rig, Pack, agent, formula, run, session,
workspace, branch, or tracker state.

After explicit restoration, preflight every identity and prerequisite declared
by the owner rule, including current runtime state, authority, non-derivable
current-process credentials, repository integration target, and complete landing
evidence. Use only the current owner interface. The first dispatch, child,
observation, gate, publication, or integration failure propagates unchanged; no
retry, alternate provider/model/credential, compatibility syntax, partial
landing, or inferred closure is allowed. Cleanup preserves the first cause and
removes partial orchestration residue.
