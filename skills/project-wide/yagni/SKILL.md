# YAGNI

Exterminate behavior, options, abstractions, dependencies, extension points, and
compatibility surfaces that lack a current requirement, current consumer, and
reachable runtime path. Every retained concept must justify its existence now.

Consume the evidence packet produced by `search-first`, decide only what must
exist now, and hand the surviving concept set to `ssot`. Accept one recheck after
structural remediation; do not restart discovery or reproduce the global flow,
which is owned by `search-first`. Read the
[necessity procedure](references/procedure.md) whenever the planned or existing
affected graph contains future-oriented capability.

YAGNI is not permission to delete a supported public contract, rare but real
consumer, security control, migration requirement, or operational safeguard.
Absence of one search result or telemetry event is not proof of non-use. Missing
ownership, callers, acceptance criteria, or runtime evidence blocks deletion.
