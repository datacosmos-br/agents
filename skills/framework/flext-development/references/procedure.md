# Apply the selected FLEXT contract

## Resolve the authors

Read the current operator request, selected task, repository manifest and profile.
Use the containing FLEXT superproject in attached mode; a standalone consumer
resolves the FLEXT root and local law on its own matching branch or release.
Do not infer that an arbitrary parent AGENTS.md or a global catalog entry owns
that project's architecture.

Read the exact local flext-law and the ADRs it cites for the changed subject.
This procedure does not copy their facade hierarchy, family layout, runtime
floor, service ports or operation signatures. The local authority decides those
contracts; the global catalog supplies reusable execution procedures.

## Establish the cutover

Locate the current source author, generated projections, public consumers and
concurrent WIP. Reuse the declared public primitive before adding an abstraction.
If an adapter merely duplicates its owner, rewire its consumers and remove the
superseded path in the same validated slice.

Apply architecture and generation changes through the local native ownership
boundary. Runtime interfaces and tests consume that contract; they do not invent
another family shape or redefine valid runtime behavior. Preserve scoped failure
scenarios and use the shared test facilities selected by that project.

## Validate and land

The canonical-command rule owns discovery, execution bounds, profiling and test
selection. The selected runtime rule owns real-consumer acceptance. Run the
required native gates for the complete affected contract and prove generation's
fixed point when its sources changed. A stale generated file is an obligation
at the generator, never permission to edit a projection.

The current task and global Git/phase owners supply review, integration and
retirement. Publish member integration commits before advancing umbrella gitlinks.
Keep source, integration and installed-runtime receipts distinct. A local result
or a subset of members cannot prove fleet closure.
