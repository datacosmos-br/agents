# Operator Correction Learning

Activate immediately after an operator corrects behavior and again at phase
boundaries. A correction is high-authority evidence for its stated scope, not
permission to infer broader preferences.

Read [the reconciliation procedure](references/reconciliation.md). It owns
tracker-available and explicitly suspended modes, contradiction removal,
evidence, and restoration transfer.

This is a personal, non-technological workflow. Never include it in generic,
technology, or framework project projections.
