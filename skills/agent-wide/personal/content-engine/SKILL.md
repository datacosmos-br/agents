# Content Engine

Build platform-native content without flattening the author's real voice into platform
slop.

Use for X posts/threads, LinkedIn posts, short-form video, YouTube explainers, and
repurposing articles, podcasts, demos, docs, or notes into public content. `brand-voice`
is the canonical voice layer; run it first when voice consistency matters.

Read the complete source-first workflow, platform adaptation rules, repurposing flow,
and quality gate in `references/procedure.md` (skill file).
