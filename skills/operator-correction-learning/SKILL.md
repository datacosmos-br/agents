# Operator Correction Learning

Turn explicit operator corrections into verified governance changes. A correction
is high-authority evidence, not permission to guess broader preferences.

## Activation checkpoints

Run immediately after a correction. During long work, re-run after three
material repo-state changes, at each phase boundary, and before closure. Review
operator messages since the last checkpoint for negation, replacement, scope,
and absolute language such as “never”, “only”, or “must”.

## Required cycle

1. Quote the corrected behavior and its replacement in the active Bead. Record
   scope, authority, and the concrete failure it prevents.
2. Verify the owning ledger with `bd where`; never infer a prefix or database.
3. Search canonical docs, skills, ADRs, setup templates, generated blocks, and
   `bd prime` memories for both the new rule and guidance that opposes it.
4. Resolve precedence. New operator law supersedes lower/older guidance. If two
   current operator instructions conflict materially, stop with the exact pair.
5. Edit owners, not projections. Update generated consumers through their
   generator. ADRs retain history: add a superseding ADR/status and links rather
   than silently rewriting an accepted decision.
6. Remove or correct every opposing instruction in scope. Do not leave old and
   new guidance coexisting, add a compatibility note, or weaken “never” into a
   preference.
7. Persist the stable rule with `bd remember <content> --key <stable-key>` in
   the verified ledger so `bd prime` injects it. Do not write memory files.
8. Run owner-native document, skill, projection, and runtime gates. Search again
   for the prohibited guidance and attach decisive output to the Bead.

Use [references/reconciliation.md](references/reconciliation.md) for the
evidence schema and contradiction audit.

## Distribution law

This is a personal, non-technological workflow capability. It may be copied to
personal agent homes. It must never enter generic project projections,
technology profiles, or FLEXT overlays.
